# FlexiTact

create a web app to demonstrate car infotainment interface. home screen has a split view containing map/navigation on the right (if possible show google maps or any other map that is free to use) and a left pane that has essential driving information such as speed, speed limit, drive mode, etc. on top of the screen is a status bar that contains time, battery percentage, connection status etc. bottom task bar contains widgets and shortcuts. settings button on the left, menu button on the right are fixed buttons. between the two, there's climate widget and media widget. climate widget contains temperature, steering heating, seat heating, windscreen defogger button. media widget contains play/pause, next, previous, volume and source selections
